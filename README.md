# Pacific Vision Database

An embedded database engine for on-device computer vision workloads on Apple platforms (iOS, iPadOS, visionOS, and macOS) on Apple Silicon. 

With the ever growing demand for memory, how can we as a society be responsible to use powerful yet limited resources like memory and compute optimally? 

Moreover, what does it mean to even optimally use memory and compute? Responsible usage of ANY system, no matter whether the machine provides AI capabilities or not.

Now coming to AI technologies such as Deep Learning techniques, they become computationally expensive [^1] for their extraordinary capabilities. So how can we as a society raise the ceiling of our intelligence, daily operations, and research by integrating these extremely powerful tools in our lives? We utilize these tools in an **optimal** manner. Whether it's at the user interface level or at the deepest level of the technologies we utilize in the cloud or on device. 

PacificVisionDB's engine is made with the mindset of creating an optimal embedded database for all the apple hardware platforms.

Next up is to research about FoundationDB to ensure PacificVisionDB is an extension of FoundationDB, not an obstacle.
